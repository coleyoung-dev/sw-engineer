AR Time Sale was a HARS content type that connected coupons, rewards, and event participation with AR interactions. I structured the Unity client so users could interact with AR objects in the camera view and continue into promotion or coupon reward flows.

- Designed interaction flows that connect AR object selection with coupon and reward behavior.
- Checked runtime cost and state transitions for repeatable mobile event content.
- Separated REST API data flow from Unity content state so the feature could be operated as a CMS-driven experience.
- Kept the interaction extensible so it could connect with AR Portal and minigame-style HARS content.
