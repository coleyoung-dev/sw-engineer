AR 타임세일은 쿠폰, 리워드, 이벤트성 참여를 AR 경험으로 연결하는 HARS 콘텐츠 타입입니다. 사용자가 카메라 화면 위에서 AR 오브젝트와 상호작용하고, 그 결과가 쿠폰이나 프로모션 플로우로 이어질 수 있도록 Unity 클라이언트 구조를 구성했습니다.

- AR 오브젝트와 사용자 터치/선택 이벤트를 쿠폰 리워드 흐름과 연결하는 구조를 설계했습니다.
- 모바일 환경에서 반복적으로 실행되는 이벤트형 콘텐츠를 고려해 런타임 비용과 상태 전환을 확인했습니다.
- REST API 기반 데이터 흐름과 Unity 콘텐츠 상태를 분리해 운영형 콘텐츠로 활용하기 쉽게 정리했습니다.
- AR 포탈이나 미니게임 같은 다른 HARS 콘텐츠와 이어질 수 있는 마케팅형 인터랙션으로 확장 가능하게 구성했습니다.
