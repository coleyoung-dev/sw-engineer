AR 상점스캔은 사용자가 주변 상점이나 브랜드 지점을 AR 환경에서 탐색할 수 있도록 구성한 HARS 콘텐츠 타입입니다. 모바일 앱 안에 Unity 콘텐츠가 임베드되는 구조를 기준으로, 위치와 방향 정보를 활용해 주변 대상을 시각화하고 서비스 데이터와 연결되는 흐름을 구현했습니다.

- GPS와 Compass 값을 활용해 사용자 주변의 상점 정보를 AR 콘텐츠로 표현했습니다.
- REST API 응답 데이터를 기반으로 가까운 상점 정보와 AR 마커 표시 흐름을 연결했습니다.
- Android와 iOS Native 앱에 Unity가 임베드되는 환경을 고려해 통신 인터페이스와 예외 상황을 테스트했습니다.
- 이후 HARS의 재사용 가능한 상점 탐색형 콘텐츠 모듈로 확장될 수 있도록 구조를 정리했습니다.
