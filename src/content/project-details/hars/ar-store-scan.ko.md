AR 상점스캔은 주변 상점과 브랜드 지점을 모바일 AR로 탐색하는 HARS 콘텐츠입니다. 위치, 방향, 서비스 데이터, Unity Embedded 동작을 하나의 재사용 가능한 흐름으로 연결했습니다.

- GPS와 Compass 기반으로 주변 상점을 AR로 표시했습니다.
- 상점 API 데이터를 AR 마커와 UI에 연결했습니다.
- Android/iOS 임베디드 앱 동작을 함께 점검했습니다.
- HARS에서 재사용 가능한 콘텐츠 모듈로 정리했습니다.
