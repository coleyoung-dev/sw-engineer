AR Store Scan was one of the HARS content types for helping users discover nearby stores or branded locations through an AR mobile experience. I worked on the Unity client side with an embedded mobile-app structure, connecting location, direction, AR visualization, and service data.

- Used GPS and compass values to represent nearby store information in AR.
- Connected REST API responses to nearest-store data and AR marker display flows.
- Tested Unity-to-native communication and edge cases for Android and iOS embedded environments.
- Structured the feature so it could become a reusable store-discovery module inside HARS.
