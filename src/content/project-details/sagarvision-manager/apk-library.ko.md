빌드 폴더의 APK를 찾아 앱 이름·버전·패키지 정보를 보여주는 기능입니다. 폴더 탐색과 `aapt` 분석이 오래 걸려도 WPF 화면에서 기기 선택과 다른 작업을 계속할 수 있도록 구성했습니다.

## 검색 흐름

- 폴더를 재귀 탐색하고 APK의 크기·수정 시각을 확인합니다.
- 변경되지 않은 항목은 화면의 기존 객체 또는 로컬 캐시를 재사용합니다.
- 새 파일과 변경된 파일만 `aapt`로 분석합니다.
- 분석 결과를 모아 UI 컬렉션을 한 번에 갱신합니다.

## 비동기 작업 제어

새 검색을 시작하면 이전 검색의 `CancellationTokenSource`를 취소합니다. 파일 탐색은 `Task.Run`으로 UI 스레드 밖에서 수행하고, `Progress<T>`로 분석 진행률을 화면에 전달합니다. 분석 대상은 `Task.WhenAll`로 처리하되 `SemaphoreSlim`으로 동시 `aapt` 실행을 4개로 제한했습니다.

`FileSystemWatcher`가 빌드·복사 과정에서 여러 이벤트를 연속 발생시키므로 1.5초 디바운스를 두었습니다. 읽는 중인 APK가 분석에 실패하면 파일명으로 목록에 남기고, 실패 결과는 캐시하지 않아 다음 검색에서 다시 시도합니다.

## 구현 포인트

- UI 선택을 유지하기 위해 변경되지 않은 파일의 기존 항목을 재사용했습니다.
- 파일 크기와 수정 시각으로 캐시 유효성을 확인했습니다.
- 검색 결과를 `RangeObservableCollection`에 일괄 반영해 불필요한 컬렉션 알림을 줄였습니다.
