실시간 트래킹 및 UDP 통신은 서버에서 계산한 수술 도구, 마커, AR Glass 상태를 Unity 클라이언트에 빠르게 반영하기 위한 영역입니다. 신뢰성이 중요한 데이터는 TCP에 두고, 실시간 pose 갱신은 UDP로 분리해 AR 화면 반응성을 높였습니다.

![실시간 트래킹 및 UDP 통신 데이터 플로우](/images_videos/sagarvision-realtime-tracking-udp-flow.svg)

## 통신 구조 설계

TCP는 초기화, 명령, 모델 데이터처럼 순서와 무결성이 중요한 흐름에 사용했습니다. UDP는 최신 값이 더 중요한 트래킹 데이터에 사용해 화면 반응성을 분리했습니다.

## UDP 수신 파이프라인

UDP 수신은 렌더링 흐름을 막지 않도록 별도 처리 흐름으로 구성했습니다. 수신 데이터는 필요한 검증을 거친 뒤 현재 workflow에서 의미 있는 상태로 변환했습니다.

## Unity 런타임 반영

파싱된 트래킹 상태는 Unity main thread에서 안전하게 반영되도록 연결했습니다. 이를 통해 probe, marker, AR HUD 상태가 실시간 데이터에 맞춰 갱신될 수 있었습니다.

## 워크플로우별 UDP mode 전환

수술 단계에 따라 같은 트래킹 데이터도 다른 의미로 사용되므로, workflow에 맞춰 UDP mode를 전환했습니다. 현재 화면이 필요로 하는 데이터만 시각화에 반영하도록 정리했습니다.

## 안정성 처리

잘못된 packet, port 충돌, 앱 종료 같은 운영 상황을 고려해 수신 흐름을 방어적으로 구성했습니다. 실시간성을 유지하면서도 클라이언트가 불안정해지지 않도록 하는 것이 핵심이었습니다.

## 구현 성과

Unity 클라이언트가 서버의 실시간 tracker pose를 AR/PC 화면에 안정적으로 반영할 수 있게 되었습니다. TCP 기반 workflow와 UDP 기반 실시간 갱신을 분리해 반응성과 안정성을 함께 확보했습니다.
