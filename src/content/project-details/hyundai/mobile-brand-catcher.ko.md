Mobile 간판 인식은 현대백화점 면세점 브랜드 캐처 콘텐츠에서 사용한 기능입니다. Unity 클라이언트에서 카메라 기반 인식 결과를 AR 반응, 미션 진행, UI 상태와 연결했습니다.

## 간단 로직

- 카메라 입력을 인식에 맞게 준비했습니다.
- 가장 신뢰도 높은 브랜드 결과를 선택했습니다.
- confidence와 반복 감지 조건으로 오탐을 줄였습니다.
- 인식 성공을 AR 콘텐츠와 UI에 반영했습니다.

## 상세 로직 구조

![Mobile 간판 인식 상세 로직](images_videos/hyundai/mobile/brand-catcher-logic.png)

로직은 카메라 입력, TFLite 추론, 결과 안정화, 콘텐츠 반영 흐름으로 구성했습니다. 모바일 AR 경험이 끊기지 않도록 인식 실행 주기와 렌더링 흐름을 분리했습니다.

인식 결과는 미션 데이터와 매칭해 AR 오브젝트, 사운드, 보상, UI 갱신에 사용했습니다. 모바일 운영을 위해 카메라 권한, 일시정지/복귀, Unity Embedded 상태 전환도 함께 확인했습니다.

## 구현 포인트

- 인식 처리가 Unity 프레임 흐름을 막지 않게 분리했습니다.
- 결과를 안정화한 뒤 미션 진행으로 연결했습니다.
- 미션 데이터를 AR 반응과 UI의 공통 기준으로 사용했습니다.
- 모바일 앱 상태 전환 케이스를 함께 점검했습니다.
